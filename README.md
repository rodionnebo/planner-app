# Планер ✦

Минималистичное и мощное приложение для планирования задач с эстетикой "True Black" и AI-подсказками.

## ✨ Особенности

- **True Black UI:** Идеально подходит для OLED-экранов, снижает нагрузку на глаза.
- **Интеллектуальные подсказки:** Генерация идей для задач с помощью AI (mock).
- **Облачная синхронизация:** Интеграция с Supabase для хранения ваших данных.
- **Гостевой режим:** Попробуйте приложение без регистрации с хранением в localStorage.
- **Адаптивность:** Полная поддержка мобильных устройств.
- **Горячие клавиши:** Управляйте списком задач быстрее.

## 🚀 Технологии

- **React 18** (Vite)
- **Supabase** (Auth & Database)
- **CSS Variables** (Theme management)
- **Vitest** (Unit testing)
- **Prettier & ESLint** (Code quality)

## 🛠 Установка

1. Клонируйте репозиторий.
2. Установите зависимости: `npm install`.
3. Создайте `.env` файл в корне проекта:
   ```env
   VITE_SUPABASE_URL=ваш_url
   VITE_SUPABASE_ANON_KEY=ваш_ключ
   ```
4. Запустите сервер разработки: `npm run dev`.

## 🧪 Тестирование

Запуск модульных тестов:
```bash
npm test
```

## 📜 Линтинг и форматирование

```bash
npm run lint    # Проверка ошибок
npm run format  # Автоматическое форматирование
```
